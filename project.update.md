# Project Update

This file is the update index for projects that already have the convention installed.

Use it when the repository needs to be aligned with the current convention flow.

## Source of truth

- `awc.meta.toon`
- `AGENTS.md`
- `project.overview.md`
- `project.migrations.md`
- `agent-start-here.md`

## Update flow

1. verify the bootstrap;
2. align the graph and vault exclusions;
3. inventory artifacts, loose files, and operational noise;
4. ask for approval before organizing, moving, or deleting;
5. organize the repository;
6. map documentation that needs to become contract, state, or official docs;
7. propose and, after approval, create or adjust `.spec`, `.stat`, and links;
8. consolidate with `trace_id` and keep `.stat` traceable;
9. record the result in the appropriate status file.

## Reading rule

- `README.md` remains the human landing page.
- `project.overview.md` is the agent entry point.
- `overview.md` is the default agent index inside folders when the convention is aligned.
